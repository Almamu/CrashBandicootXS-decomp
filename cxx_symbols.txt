# g++ 2.x mangled name -> the C name the rest of the build uses (#664).
# The Makefile renames these in every C++ object (CXX_OBJS) with
# `objcopy --redefine-syms` after assembling it: definitions get the
# names the C callers (and the C vtables left in src/data) use, the
# vtables g++ emits get their C table names (ldscript.txt places them),
# and references get the C names of the functions and vtables they
# point at. See docs/cplusplus.md.
#
# g++ 2.9 mangling: `Method__<len>Class<args>` for a method,
# `__<len>Class` for a constructor, `_._<len>Class` for a destructor,
# `_vt.<len>Class` for a vtable. A class in a namespace is
# `Q<parts><len>Ns...<len>Class` (`Setup__Q36Engine3Sys3Irq`, #1033);
# tools/cxx_rename.py updates this file when a class moves.
#
# The global operators (g++ 2.x's assembler names; the game's own
# replacements, `operator new` & co., are in src/level/camera.cpp)
__builtin_new OperatorNew
__builtin_delete OperatorDelete
__builtin_vec_new OperatorNewArray
__builtin_vec_delete OperatorDeleteArray
