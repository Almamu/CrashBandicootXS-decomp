# Corrections applied to build/expected/target.o (the merge of
# expected/code_3.s and expected/legacy.s - see Makefile's `report`
# target) after assembling, never to either frozen source itself (see
# docs/decomp_dev.md and expected/README.md for why). Kinds of entry,
# one per line:
#
#   rename OLD_NAME NEW_NAME
#     A function that was still `sub_XXXXXXXX` in the frozen disassembly
#     (commit 710cc9a) got a real, descriptive name at or after the point
#     it was matched to C (rather than in the one dedicated renaming pass
#     that commit 710cc9a itself already captured) - without this, the
#     function doesn't appear in decomp.dev's report at all, since target
#     and base would disagree on its name and objdiff pairs symbols by
#     name within a unit.
#
#   split ADDRESS NAME
#     The original disassembly never gave this address its own function
#     label at all - later matching work discovered it's actually a
#     separate function from whatever precedes it. Without this, both
#     the real preceding function AND this one report a wrong match
#     percentage (the preceding one appears too large, and this one
#     doesn't appear at all).
#
#   unlabel NAME
#     The opposite of `split`: the original disassembly labelled this
#     address as a function start, but the C source has no such function
#     (a return point inside a function, or a label that landed mid-
#     instruction). The symbol becomes a plain local label, and its bytes
#     count toward the function before it. Without this, that preceding
#     function looks too small next to its base, and the label shows up
#     as an extra, never-matched function.
#
#   code ADDRESS / data ADDRESS
#     Adds a `$t` / `$d` ARM mapping symbol at ADDRESS, for code the
#     frozen source only has as a raw `.byte` blob (objdiff decodes a
#     data region as `.word`s, not instructions).
#
#   resolve NAME
#     NAME starts right where a unit's range ends, and the base object
#     calls it with no relocation (through a local alias of a function it
#     defines itself). A local label for NAME at the end of the target's
#     slice makes the target's calls resolve the same way (see
#     tools/slice_expected.py). No entry needs it at the moment: its one
#     user, libgcc2.c's calls to sub_8037E54, went away when that
#     function was named `__udivsi3` and the `.set` alias was dropped
#     (the calls now carry relocations, which the `rename` below pairs).
#
# Add a line here whenever a newly-matched function doesn't show up in
# the report, or reports an unexpectedly low match percentage - see
# docs/decomp_dev.md for how to tell the difference between this and a
# genuine mismatch.
