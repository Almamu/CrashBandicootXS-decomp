# The game's functions named as the C library's (engine/src/engine/util/): the
# pc platform renames them in the game's objects (platform.mk, objcopy
# --redefine-syms), so that the host's C library keeps its own for its
# other users (platform/pc/src/, libstdc++). Their callers in the game are
# renamed with them. host_link.py --libs checks that the list is complete.
rand GameRand
srand GameSrand
sprintf GameSprintf
vsprintf GameVsprintf
strcat GameStrcat
strcpy GameStrcpy
strlen GameStrlen
strncpy GameStrncpy
# The global operator new and delete (operator_new.cpp, the game's heap):
# a program may replace them, but then every C++ library in the process
# uses them too, before the game has set its heap up (SDL's audio loads
# libjack, whose constructors allocate). The game keeps its own under
# these names; host_link.py gives OperatorNew & co. (cxx_symbols.txt) the
# renamed definitions.
_Znwm GameOperatorNew
_Znam GameOperatorNewArray
_ZdlPv GameOperatorDelete
_ZdaPv GameOperatorDeleteArray
